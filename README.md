# homebrew-engram

Homebrew tap for [Project Engram](https://github.com/ek33450505/project-engram) — persistent AI identity framework for Claude Code.

## Install

```bash
brew tap ek33450505/engram
brew install engram
```

## Post-install

```bash
engram init
bash $(brew --prefix)/opt/engram/libexec/scripts/cast-install.sh
```
